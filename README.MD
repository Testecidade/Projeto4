# Sobre
Este é um projeto para entender funcionalidades básicas sobre JavaScript e CSS.

Como conceitos simples sobre animações e funcionalidades para modificar o estado da página com um botão para alternar entre modo claro e modo escuro.

# Uso

Para utilizar esse repositório precisa ter a extensão Live Server instalado no seu VsCode, após a instalação da extensão é necessário clonar o repositório e depois apenas rodar o projeto com o Live Server

# Observações

Este é um projeto simples com poucas funcionalidades apenas para guardar a progressão e o aprendizado com a criação de sites.
